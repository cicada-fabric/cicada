# Support

Read the [technical guide](docs/v01-technical-guide.md),
[documentation index](docs/README.md) and [deployment guide](docs/distribution.md)
first. The current candidate is unreleased and has incomplete product acceptance;
there is no guaranteed support schedule or service-level agreement.

Use [repository issues](https://github.com/cicada-fabric/cicada/issues) for
non-sensitive bugs, documentation questions and feature requests. For Android
implementation questions, use the
[Client repository](https://github.com/cicada-fabric/cicada-client).
For vulnerabilities, follow [SECURITY.md](SECURITY.md).

Include the source revision and dirty state, software and Runtime versions,
relevant contract/schema versions, deployment type and a minimal reproduction.
Explain expected and actual results, and distinguish local tests from native,
Android or public HTTPS observations. Share only sanitized log excerpts; remove
credentials, private host paths, personal data and message bodies. Synthetic
examples are preferable to a full deployment archive.
