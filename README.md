# CICADA

CICADA is under active development and has not had a public release. Development happens on the [`dev`](https://github.com/cicada-fabric/cicada/tree/dev) branch; `main` is an unreleased placeholder, not a deployable product snapshot.

The planned first public release line is `v0.1.x`. Until a release is published, use the development branch and its documentation for current code, tests, and limitations. No GitHub Release is available yet.
